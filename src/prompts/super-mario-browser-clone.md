Write a fully functional, complete clone of Super Mario Bros., the famous NES game.

- The clone must work in a web browser from a single `index.html` file with no server.
- Include a decent replica of the graphics and assets using self-contained code and browser APIs.
- Make it colorful and playable, with a scrolling level, platforms, enemies, collectibles, a goal, and win/game-over states.
- Support these controls: Up, Down, Left, Right, Spacebar to jump, and Shift to speed up.
- Keep the implementation complete and polished enough to play through in the browser.

## Notes

This prompt tests whether a model can build a complete interactive game from a single file while handling rendering, input, physics, collision detection, camera movement, and game state without relying on a server or external libraries.
