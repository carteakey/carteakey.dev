Use the attached reference image as the primary visual target.

Reproduce the reference image as closely as possible as a playable video game or interactive tech demo that runs in a web browser. Prioritize visual similarity to the reference: composition, scale, perspective, color palette, lighting, environment, and the relative size and placement of human figures.

Make the result polished, colorful, detailed, animated, and interactive. Continue iterating on the implementation while there are clear improvements available along the goal of matching the reference image. Fix any browser console errors and verify that the final result works correctly in the browser.

## Notes

This prompt tests visual instruction following, image-to-code translation, browser interactivity, animation, and an agent's ability to keep refining a result against a visual target.
