Software bloat creeps in quietly. An electron wrapper here, an auto-updating daemon suite there, and suddenly an idling machine is chewing through gigabytes of RAM before you even write a line of code or play a song.

This infographic breaks down 11 heavy desktop apps and the native, lightweight tools that replace them—with measured resident memory (RSS), disk sizes, and explicit tradeoffs.

### The Audit Summary

- **The Big Three (Engine Elimination):** The heaviest resource offenders are almost always browser-engine abstractions. Replacing WhatsApp with **ZapFast** (Rust/egui) or Spotify with **Spotifast** drops active memory from ~600MB+ down to ~35–42 MB because there is no Chromium runtime or CEF layer running in the background.
- **Replacing Hardware Daemons:** Vendor display suites (like Dell Display Manager or LG OnScreen Control) regularly bundle background analytics and multiple helper processes. **MonitorControl** replaces 350 MB of disk footprint and 200 MB+ of RAM with a clean 40 MB Swift utility communicating directly over DDC/CI.
- **Smaller is Not Free:** Every swap gives up something. Zed gives up VS Code's vast extension marketplace; Obsidian gives up Notion's real-time multi-user databases; ZapFast gives up audio/video calls. The win is knowing what you traded away.
