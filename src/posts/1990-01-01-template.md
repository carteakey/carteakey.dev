### Definition Popovers, Sidenotes, and Handwritten Annotations

- **Definition popover (`define`)**: Hover or focus {% define "Workbench UI", "A dense, paper-like interface for repeated reading and writing workflows." %} to inspect the tooltip.
- **Right & Left Sidenotes (`sidenote`)**: Factual margin notes sit calmly in the rail on wide screens: {% sidenote "Right-hand factual sidenote: calm editorial context." %}this phrase has a right sidenote{% endsidenote %}, and {% sidenote "Left-hand factual sidenote: stays clear of the right rail.", "left" %}this phrase has a left sidenote.{% endsidenote %}

## 7. Frontmatter Reference

| Field | Values | Effect |
| :--- | :--- | :--- |
| `hidden: true` | bool | Excludes from all listings; shows "Hidden local preview" banner |
| `draft: true` | bool | Listed publicly; shows "Draft: work in progress" banner; excluded from featured |
| `featured: true` | bool | Shows in ★ Featured slot on homepage (newest wins; draft posts excluded) |
| `featured: { weight: 1 }` | object | Explicit weight for featured ordering (lower wins) |
| `pinned: true` | bool | Floats to top of feed and post listings |
| `authored_by` | `human` \| `ai-assisted` \| `ai-generated` | Authorship badge and banner; omit = Unclassified |
| `theme: editorial` | string | Enables editorial prose treatment and optional left-rail `sidebar` |
| `attribution` | object | Renders top "Adapted from..." source attribution panel before the body |
| `sources` | list | Renders bottom "Sources and acknowledgements" panel after the body |
| `updated` | date | "Updated" date; must match the newest row in the post's `## Changelog` table |
| `giscusTerm` | string | Overrides the Giscus comment thread URL (retains comments after a slug/folder move) |
